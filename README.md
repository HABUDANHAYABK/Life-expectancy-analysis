# Life Expectancy Analysis

This project explores global life expectancy trends and their relationship with socioeconomic and environmental factors using data analysis and visualization in Python.

## Dataset

The dataset contains global information on:
- Life expectancy (World Bank)
- CO2 emissions
- Health & education expenditures
- Undernourishment
- Unemployment
- Sanitation
- Injuries, communicable and non-communicable diseases
- Corruption
- Region, income group, country name/code
- Year

## Objectives

- Clean and preprocess the dataset
- Explore trends in life expectancy across regions and income groups
- Visualize relationships between life expectancy and key indicators
- Perform basic statistical analysis to uncover insights

## Tools and Libraries

- Python (pandas, seaborn, matplotlib)
- Jupyter Notebook
- Git/GitHub
